# Wizard Survivors

Survivor-like, где заклинания кастуются рисованием знаков. Рисуешь знак пальцем или мышью, игра его распознаёт и применяет заклинание.

Играть: https://prizrakzamkov.itch.io/wizard-survivors (в браузере, на странице есть и сборка под Android)

## Что внутри

Основной код лежит в `Assets/Scripts`:

- `UIGestureLine`, `SignDatabase`, `SpellSystem` - линия, которую рисует игрок, набор знаков и заклинания
- `EnemySpawnDirector`, `EnemyBehaviour`, `EnemyStatusEffects` - волны врагов и эффекты вроде заморозки и замедления
- `InfiniteHexTilemap`, `WorldWrapManager` - бесконечная карта, которая заворачивается вокруг игрока
- `CameraShake`, `ImpactFlash` - отклик на попадания

Знаки и заклинания настраиваются через ScriptableObject, сами данные лежат в `Assets/Configs`.

## Почему проект не собирается целиком

Часть скриптов в публичной копии убрана намеренно: код открыт для просмотра, но собрать из него игру целиком нельзя (хотя может и получится, не проверял). Возможно, я ещё вернусь к проекту. Рабочая версия лежит на itch.io по ссылке выше.
