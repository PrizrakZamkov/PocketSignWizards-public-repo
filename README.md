# Wizard Survivors

2D survivor-like игра на Unity, в которой заклинания активируются с помощью рисования символов. Игрок рисует знак пальцем или мышью, игра распознаёт его и запускает соответствующее заклинание.

**Играть:** [браузерная версия и Android-сборка на itch.io](https://prizrakzamkov.itch.io/wizard-survivors)  
**Статус:** разработка временно приостановлена

## Игровые механики

- **Заклинания через жесты.** Ввод символов с помощью мыши или сенсорного экрана и их связь с игровыми заклинаниями.
- **Разные типы заклинаний.** Направленные атаки, заклинания по области, снаряды, цепные попадания и визуальные эффекты.
- **Эффекты на врагах.** Замедление, оглушение, горение, отравление и заморозка.
- **Поведение противников.** Преследование игрока с учётом его движения и отталкивание соседних врагов, чтобы они меньше скапливались в одной точке.
- **Система спавна.** Управление количеством появляющихся врагов, события с усиленными группами и боссами, адаптация сложности (работает не оч).
- **Бесконечный мир.** Hex Tilemap и зацикливание игрового пространства вокруг игрока.
- **Обратная связь.** Вспышки при попаданиях, тряска камеры, частицы и UI-индикаторы применения заклинаний.

## Реализация

Основная часть доступного кода находится в `Assets/Scripts`, настройки игровых систем — в `Assets/Configs`.

| Скрипт / группа | Назначение |
|---|---|
| [`UIGestureLine.cs`](Assets/Scripts/UIGestureLine.cs) | Отображение линии, которую игрок рисует на UI |
| [`SignDatabase.cs`](Assets/Scripts/SignDatabase.cs) | Данные о символах: идентификатор, название, XML-файл и описание |
| [`SpellSystem.cs`](Assets/Scripts/SpellSystem.cs) | Реестр заклинаний, запуск заклинаний, кулдауны, снаряды и эффекты |
| [`EnemySpawnDirector.cs`](Assets/Scripts/EnemySpawnDirector.cs) | Цикл спавна, события, лимиты и адаптация сложности по активности игрока |
| [`EnemyMovement.cs`](Assets/Scripts/EnemyMovement.cs) | Преследование игрока с прогнозом его позиции и separation между врагами |
| [`EnemyStatusEffects.cs`](Assets/Scripts/EnemyStatusEffects.cs) | Временные эффекты: slow, stun, burn, freeze |
| `InfiniteHexTilemap`, `WorldWrapManager` | Бесконечная карта и зацикливание игрового пространства |
| `CameraShake`, `ImpactFlash` | Визуальная обратная связь при попаданиях и других событиях |

### Технические решения, которые можно посмотреть в коде

- **ScriptableObject** для хранения настроек заклинаний и параметров спавна отдельно от логики компонентов.
- **Словари и коллекции** для поиска заклинаний по имени, хранения кулдаунов и управления активными эффектами.
- **Coroutines** для временных эффектов, циклов спавна и последовательностей применения заклинаний.
- **Physics2D** для поиска противников и обработки взаимодействий между игровыми объектами.
- **Unity UI** для отображения пользовательского жеста и состояния заклинаний.
